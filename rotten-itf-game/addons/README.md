Drop this scene into your Godot project and you’re basically done.
### What it does
Simple scrolling credits system driven by a data array. No UI setup, no extra plugins.

### How to use
* Add the scene to your project
* Open the script and edit `credits_data`
* Set `main_menu_scene` if you want to return somewhere after credits
* Adjust `scroll_speed` if it feels too fast or too slow
* Run the scene

### Controls
* ESC skips credits

That’s it.
